🖥️ Vibe Coding Setup Guide

Everything on this page assumes you've never opened a terminal before. By the end, you'll have Node.js, Git, VS Code, and (optionally) Claude Code running on your own machine — the same tools used in the talk.

WHAT YOU'LL HAVE WORKING BY THE END

  • A terminal that understands node -v and npm -v
  • Git installed, so git push actually works
  • VS Code, so you can see and edit the files Claude writes
  • (Optional) Claude Code, so Claude can run those commands for you
1

Install Node.js & npm

Next.js — and the app you'll build — runs on Node. npm (Node's package manager) comes bundled with it.

  1. Go to nodejs.org and download the button labeled LTS.
  2. Open the downloaded .pkg file and click through the installer (defaults are fine).
  3. Open the Terminal app (search for it with Spotlight — Cmd + Space, type "Terminal").
  4. Check it worked:
  1. Go to nodejs.org and download the button labeled LTS.
  2. Run the downloaded .msi installer. Keep clicking Next — leave "Add to PATH" checked (it's on by default).
  3. Open PowerShell (search for it in the Start menu).
  4. Check it worked:
node -v
npm -v

Both should print a version number (like v22.11.0). If you instead see "command not found," close the terminal completely and reopen it — installers set your PATH, but windows already open don't see the update.

2

Install Git

Git is the tool that actually does git push — separate from having a GitHub account.

  1. Open Terminal and type:
git --version

If it's not already installed, macOS will pop up a prompt to install the "Xcode Command Line Tools." Click Install and wait a few minutes — that installs Git along with it.

  1. Go to git-scm.com, download, and run the Windows installer.
  2. Keep the default options — this also installs Git Bash, a terminal you can use instead of PowerShell if you prefer.
  3. Verify in PowerShell or Git Bash:
git --version
3

Set up GitHub authentication

GitHub no longer accepts your account password for git push — you need a token instead.

  1. On github.com, click your profile photo → Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. Generate a new token, check the repo scope, and copy the token somewhere safe — GitHub only shows it once.
  3. The first time you git push from a new machine, it'll prompt for a username and password. Enter your GitHub username, then paste the token as the password.
Shortcut: installing the GitHub CLI and running gh auth login sets this up automatically, no token-copying required.
4

Install VS Code

This is where you'll actually see the files Claude writes, and where you'll run the terminal commands above going forward.

  1. Download from code.visualstudio.com — it's a .zip.
  2. Unzip it and drag Visual Studio Code into your Applications folder.
  3. Open it, then open the built-in terminal with Cmd + \` (backtick, top-left of your keyboard).
  1. Download from code.visualstudio.com — the "Windows" button.
  2. Run the installer; leave "Add to PATH" checked.
  3. Open it, then open the built-in terminal with Ctrl + \` (backtick).

From here on, do everything — npm install, git push, running Claude Code — from this built-in terminal, so it's always in the right project folder.

5

Install Claude Code optional

Lets Claude create files, run npm install, and push to GitHub directly — instead of you copy-pasting code out of a chat window by hand.

In the VS Code terminal:

npm install -g @anthropic-ai/claude-code

Then start it and log in with your Claude account:

claude
6

Final check

Run all of these in one go — every line should print a version number.

node -v
npm -v
git --version
code --version
claude --version

Skip the last line if you didn't install Claude Code. If everything prints a version, you're ready to build.

7

Troubleshooting

"node" or "npm" is not recognized / command not found

Fully quit and reopen your terminal (or restart your computer). The installer updates your PATH, but a terminal window you already had open won't see the change.

PowerShell won't run npm — "running scripts is disabled"

Open PowerShell as Administrator once and run Set-ExecutionPolicy RemoteSigned, then type Y to confirm. Or just use Git Bash instead of PowerShell — it doesn't have this restriction.

"permission denied" (EACCES) installing global npm packages

Don't use sudo — it causes more problems later. This usually means Node was installed in a way that needs admin rights for global installs; reinstalling Node from the official nodejs.org installer (not Homebrew) usually fixes it.

git push asks for a password and then rejects it

GitHub disabled plain password auth for git operations. Use a personal access token as the password (Step 3), or set up the GitHub CLI with gh auth login.

"code" command doesn't work in Terminal

Open VS Code, press Cmd+Shift+P, type "Shell Command," and choose Install 'code' command in PATH.
